# Étude du marché — « Studio Pop »

Méthode : lecture des pages via un agent de lecture web (texte uniquement, pas de rendu visuel).
**Limite honnête** : beaucoup de sites sont rendus en JavaScript ou en PDF compressé, donc plusieurs
références n'ont rien donné d'exploitable. Je ne complète pas de mémoire : seuls les points lus sont notés.

## Duolingo — langage de formes (blog.duolingo.com)
Lu. design.duolingo.com/illustration redirige vers une liste d'articles (pas de guide).
- Silhouettes lisibles : « le moins de détails possible », formes bien détachées, espace autour.
- Exagération et rythme : on pousse les formes presque jusqu'à la caricature, tailles variées.
- L'animation guide l'attention (les icônes animées retiennent plus que le statique).
- À éviter : surcharger les visuels ; l'illustration ne doit jamais interrompre le jeu.
→ Retenu : mascotte à 4 expressions très simples, boutons 3D, mouvement réservé aux temps forts.

## NN/g — Néo-brutalisme
Lu en entier.
- Une seule ombre pleine décalée (~4 px), sans flou ni dégradé, comme unique effet de relief.
- 2 à 3 couleurs vives maximum, attribuées de façon stable, sur base noir/blanc cassé.
- Contours épais d'une seule couleur foncée, épaisseur constante, marges 24–32 px.
- Limites : le contraste du texte doit respecter les standards (jaune + cyan cité comme échec) ;
  texte courant en police neutre ; états interactifs clairs.
→ Retenu : contour 2 px encre, ombre pleine 4 px, texte courant Nunito, **texte encre sur jaune/cyan/vert**.

## daisyUI — tendances « bold & experimental »
Page d'index lue (pas la fiche détaillée).
- Répéter un petit jeu de décisions (1 épaisseur de contour, 1 décalage, 1 rayon).
- Garder les codes conventionnels du quiz et n'habiller que l'enveloppe.
- Énergie « dopamine » (couleurs saturées) réservée aux écrans de score/célébration.
- À éviter : motifs et lettrages déformés sous le texte de la question.
→ Retenu : décor flottant uniquement sur les temps forts, jamais derrière la question.

## Jackbox Games
Page texte seulement (pas de couleurs/typo lisibles).
- Rejoindre sans friction ; séparer le spectacle (grand écran) de l'action (téléphone).
- Ton chaleureux et drôle jusque dans les textes secondaires.
- À éviter : reconnexion manuelle.
→ Retenu : textes secondaires avec personnalité, révélations pensées pour toute la tablée.

## Non exploités (échec de lecture)
Kahoot (PDF illisible, seul indice : Montserrat), Trivia Crack et Heads Up (rendu JavaScript, corps vide),
Dribbble / LottieFiles / comparatifs App Store : non consultés (contenu dynamique, pas de navigateur visuel
dans cet environnement). Aucune idée n'en est tirée.
